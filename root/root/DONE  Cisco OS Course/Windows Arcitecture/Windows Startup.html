Windows Startup

Registry Items

two important registry items that are used to automatically start applications and services:

  • HKEY_LOCAL_MACHINE - Several aspects of Windows configuration are stored in this key, including information about services that start with each boot.
  • HKEY_CURRENT_USER - Several aspects related to the logged in user are stored in this key, including information about services that start only when the user logs on to the computer.

 

Different registry entries have different flags which defines how they are started such as: 

Run, RunOnce, RunServices, RunServicesOnce, and Userinit

You can enter registry items manually but using the MSconfig.exe is easier and safer
