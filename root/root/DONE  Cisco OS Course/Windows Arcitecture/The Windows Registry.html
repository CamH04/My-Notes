The Windows Registry

Info about almost anything is stored in the registry 

Registry is split up into hives → keys → sub-keys in a hierarchical structure

 

Registry keys can contain a sub-key or a value.

Value Types a key can hold:

  • REG_BINARY - Numbers or Boolean values
  • REG_DWORD - Numbers greater than 32 bits or raw data
  • REG_SZ - String values
