Windows Booting

 

Stage 1 (POST)

  • BIOS Firmware:
  • All hardware devices : Init and Power On Self Test (POST) are done
  • Then System Disk is discovered , ending the POST
  • Last Instruction of the POST sends to the Master Boot Record (MBR)
  • Bios Executes the MBR program (finding and loading OS)  

Note: UEFI firmware has a lot of visibility into the boot process. UEFI boots by loading EFI program files, stored as .efi files in a special disk partition, known as the EFI System Partition (ESP).

 

Stage 2:

  • Bootmgr.exe is run, switching from real to protected mode to use all system memory
  • Bootmgr.exe reads the Boot Configuration Database (BCD), contains more code to boot with a flag saying whether is coming out of hibernation or a fresh start 
    • If it comes out of hibernation: Winresume.exe is run. This allows the computer to read the Hiberfil.sys file which contains the state of the computer when it was put into hibernation
    • If a full start: Winload.exe is ran, creates a record of the hardware configuration in the registry, uses Kernel Mode Code Signing (KMCS) to make sure that all drivers are digitally signed
  • Ntoskrnl.exe is ran., starts the Windows kernel and sets up the HAL
  • Session Manager Subsystem (SMSS) reads the registry to create the user environment and sets up the WinLogon Service
