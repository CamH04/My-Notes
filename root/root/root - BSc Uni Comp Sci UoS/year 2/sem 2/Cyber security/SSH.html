SSH is not a shell, it only creates a channel to run a shell remotley (like the unix rsh command)

SSH is a protocol
ssh is the terminal program

 

SSH comes with authentication (identity checks) , encryption and integrity checks

 

SSH can port forward:

Reroutes a TCP/IP connection to pass through an SSH connection, transparently encrypting it end-to-end (ftp)

Port forwarding can also enable applications to redirect through network firewalls that otherwise would
have prevented it (firewall subversion)
